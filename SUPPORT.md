# Support

- **Questions and usage help:** open a GitHub Discussion or an issue at https://github.com/shahvatsalofficial/intentsutra-ai/issues
- **Bugs:** use the bug report template. Include `intentsutra version`, your OS, Node version and the exact command. Remove tokens, usernames, private paths and real system names first. Attach the `audit-report.md` if relevant.
- **Security problems:** do **not** open a public issue. See [SECURITY.md](SECURITY.md).
- **Legal, regulatory or safety questions about your product or release:** this project cannot answer them. Ask qualified legal, privacy, security and domain reviewers.
- **Response times:** this is a volunteer project. No SLA is offered or implied.
