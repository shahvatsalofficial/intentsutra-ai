# Testing strategy

Unit: parser, stable IDs, normalization, schema, unanswered questions, candidate acceptance. Integration: import/revision/approval/link/attestation, stale evidence, audit chain, JSON/MD/HTML report. Security: symlink/path traversal, oversize input, report escaping, no CORS, GET-only auth, overwrite refusal. End-to-end: CLI doctor/demo and clean ZIP extraction. Future: property-based/fuzz tests, multi-process concurrency, real Git/CI/test runner, host-specific IDE integration, Windows/macOS CI, production load and accessibility tests.
