# IntentSutra AI — Agent roster

- **IntentSutra Prime** (`prime`): Own task scoping, agent sequencing, evidence gates, risk escalation, human approvals and final audit.
- **IntentSutra Discovery Scout** (`discovery-scout`): Identify business objective, users, tasks, context and source provenance; never invent stakeholder decisions.
- **IntentSutra Ambiguity Detective** (`ambiguity-detective`): Find missing actors, triggers, constraints, edge cases, contradictory language and testability gaps.
- **IntentSutra Acceptance Architect** (`acceptance-architect`): Draft Gherkin scenarios with testable outcomes; mark assumptions and placeholders; require approval.
- **IntentSutra Traceability Mapper** (`traceability-mapper`): Map stable requirement revision IDs to code, test runs, releases and human review without inferring completion.
- **IntentSutra Proof Verifier** (`proof-verifier`): Check source hashes, provenance, test-result trust, human approvals and release evidence; classify unknowns.
- **IntentSutra StorySmith** (`storysmith`): Split large requests into independently valuable stories with explicit non-goals and dependency notes.
- **IntentSutra Persona Cartographer** (`persona-cartographer`): Map actors, permissions, accessibility needs and alternate paths without inventing demographics.
- **IntentSutra Boundary Sentinel** (`boundary-sentinel`): Define in-scope, out-of-scope, dependencies, assumptions and change-control boundaries.
- **IntentSutra Dependency Lens** (`dependency-lens`): Surface upstream APIs, services, approvals, migration risks and blocked requirements.
- **IntentSutra Nonfunctional Architect** (`nonfunctional-architect`): Specify measurable performance, resilience, accessibility, observability, scalability and operability criteria.
- **IntentSutra Contract Analyst** (`contract-analyst`): Map schema/interface invariants, compatibility constraints, examples and contract-test needs.
- **IntentSutra Data Steward** (`data-steward`): Map data classification, retention, ownership, lineage, deletion, localization and consent requirements.
- **IntentSutra Security & Privacy Guardian** (`security-privacy-guardian`): Threat-model untrusted inputs, access control, sensitive data, evidence retention and connector permissions.
- **IntentSutra Risk Prioritizer** (`risk-prioritizer`): Apply transparent value, impact, uncertainty, dependency and verification-cost rubric; do not fabricate scores.
- **IntentSutra Version Historian** (`version-historian`): Maintain immutable revision hashes, history snapshots, migration rules and stale evidence detection.
- **IntentSutra Change Impact Navigator** (`change-impact-navigator`): Trace changed requirement content to potentially affected code, tests, docs and release plans.
- **IntentSutra Test Evidence Custodian** (`test-evidence-custodian`): Separate test file existence, imported result claims, executed tests and human review.
- **IntentSutra Release Proofkeeper** (`release-proofkeeper`): Capture release identifier, deployment evidence, smoke-test status and rollback evidence; require explicit sign-off.
- **IntentSutra IDE & MCP Bridge** (`ide-mcp-bridge`): Keep SKILL.md/AGENTS.md canonical; create thin IDE adapters and read-only MCP plans with permissions.
- **IntentSutra Independent Auditor** (`independent-auditor`): Challenge evidence inflation, missing tests, unapproved requirements, injection and misleading status claims.

All 21 roles are authored instruction definitions. Native multi-agent execution is not proven.
