# Release quality gate (not yet completed)

- [ ] Dependency licenses reviewed and NOTICE files checked
- [ ] Automated tests pass after clean install on Windows, macOS and Linux
- [ ] Actual native IDE activation verified and version documented
- [ ] Secret scanning, SAST, dependency audit and SBOM evidence captured
- [ ] No fabricated approval or automatic completion inference
- [ ] Multi-process audit and transaction design reviewed
- [ ] User docs, CLI help, samples and privacy notice validated
- [ ] Human maintainer signs public release; npm/GitHub name availability verified
- [ ] Signed release artifact and rollback instructions published

Passing M0 unit tests does not satisfy these release gates.
