# Legal and trust

Informational only; not legal advice.

- **License:** Apache-2.0 (see LICENSE, NOTICE). Zero runtime dependencies, so no third-party code is redistributed.
- **No certification:** an audit PASS means the recorded evidence is internally consistent. It is not a compliance opinion, a security certification or proof that software is correct.
- **No verified identity:** approvals are self-attested; reviewer names can be typed by anyone with local access.
- **No test execution:** imported test-run and release outcomes are user claims, labelled "not independently verified".
- **Trademarks:** third-party product names are used only to describe compatibility; no affiliation or endorsement. The name "IntentSutra" has not been trademark-searched.
- **Privacy:** local only; no telemetry or network calls. Do not store real secrets or personal data in requirements.
- **Accessibility:** reports use semantic HTML and visible focus; WCAG 2.2 is a design reference and conformance is not claimed.
- **Status labels used in this project:** implemented, tested-on-<platform>, authored-only, mock-tested, candidate, planned, not-run, blocked, unsupported.
