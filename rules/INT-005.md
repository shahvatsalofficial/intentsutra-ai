# INT-005 — Data minimization

**Normative policy:** Avoid secrets and PII in reports; redact common secret patterns and document limitations.

**Agent enforcement:** Before any claim, identify the exact requirement revision, evidence provenance and whether the action actually executed. Block unauthorized writes and approval bypasses. Escalate missing facts to the human owner.

**Automated coverage:** The offline CLI implements only the specific gates documented in `docs/STATUS.md`; this rule file is broader policy, not proof of universal enforcement.

**Audit evidence:** CLI test, report artifact, or explicit `not-run` with reason. **Owner:** Vatsal Shah.
